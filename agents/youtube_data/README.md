# YouTube Data Agent
Vai trò: Fetch, analyze YouTube channel data, video performance.

## File ownership
- `video_inventory.csv` — all videos
- `all_videos.json` — full video data
- `channel_info.json` — channel metadata

## Dependencies
- YouTube Data API v3 key

## API quota
- Cẩn thận quota — playlistItems return metadata only, videos API cần để lấy statistics
