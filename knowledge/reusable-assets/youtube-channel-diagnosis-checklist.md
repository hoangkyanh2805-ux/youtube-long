# Danh Sách Kiểm Tra Hermes Dashboard Chẩn Đoán Kênh YouTube

Dùng danh sách này để chạy lại quy trình trong video từ khoảng 06:44: tự cài Hermes, mở dashboard, đưa URL kênh, chẩn đoán, cấp YouTube Data API nếu cần, rồi biến kết quả thành tài sản nội dung.

## 1. Tự Cài Hermes

- [ ] Đã có nguồn cài Hermes chính thức hoặc đoạn video hiển thị lệnh cài.
- [ ] Chạy lệnh cài Hermes. Bản chép lời chỉ nói “một dòng lệnh” nhưng không ghi rõ lệnh cụ thể.
- [ ] Trả lời các câu hỏi cấu hình trong quá trình cài.
- [ ] Chọn các tùy chọn phù hợp với máy và quy trình.
- [ ] Gõ `H` sau khi cài.
- [ ] Thiết bị đầu cuối hiện thông tin Hermes, xem như cài thành công.

## 2. Mở Dashboard Local

- [ ] Hermes dashboard chạy được trên máy.
- [ ] Kiểm tra địa chỉ localhost. Trong bản chép lời, dashboard được nhắc ở cổng 304.
- [ ] Dashboard không bị trắng hoặc lỗi tải.
- [ ] Có thể yêu cầu Hermes tải kỹ năng/công cụ cần thiết.
- [ ] Có thể tạo đầu ra dạng màn hình, dashboard hoặc hình ảnh.

## 3. Kết Nối Quy Trình Cá Nhân

- [ ] Xác định Hermes sẽ hỗ trợ việc gì: nghiên cứu thị trường, tạo nội dung, báo cáo hằng ngày, Telegram hoặc chẩn đoán kênh.
- [ ] Nếu dùng Telegram, kiểm tra kết nối Telegram.
- [ ] Nói rõ cho Hermes các thói quen làm việc quan trọng.
- [ ] Nói rõ công cụ thường dùng để làm video.
- [ ] Nói rõ công cụ thường dùng để chuyển văn bản thành giọng nói nếu có.
- [ ] Yêu cầu Hermes ghi nhớ các lựa chọn lặp lại.

## 4. Đưa URL Kênh YouTube

- [ ] Có URL kênh YouTube cần phân tích.
- [ ] Đưa URL kênh cho Hermes.
- [ ] Yêu cầu Hermes lấy dữ liệu công khai trước.
- [ ] Kiểm tra Hermes nhận diện đúng tên kênh.
- [ ] Kiểm tra Hermes nhận diện số lượng/video dạng nội dung chính.
- [ ] Ghi rõ đây mới là dữ liệu công khai, chưa phải dữ liệu phân tích sâu.

## 5. Chẩn Đoán Lần 1 Bằng Dữ Liệu Công Khai

- [ ] Hermes chỉ ra điểm mạnh của kênh.
- [ ] Hermes chỉ ra điểm yếu của kênh.
- [ ] Hermes chỉ ra điểm mù người làm kênh có thể chưa thấy.
- [ ] Hermes đưa ra hướng chiến lược hoặc “đơn thuốc” cải thiện.
- [ ] Gợi ý đủ cụ thể để có hành động tiếp theo.
- [ ] Không xem nhận định từ dữ liệu công khai là kết luận cuối cùng.

## 6. Chuẩn Bị YouTube Data API Nếu Cần Phân Tích Sâu

- [ ] Vào Google Cloud.
- [ ] Mở khu vực API & Services.
- [ ] Bật YouTube Data API.
- [ ] Vào Credentials.
- [ ] Tạo khóa YouTube Data API.
- [ ] Không ghi khóa API vào file Markdown.
- [ ] Không lưu khóa API trong kho dự án.
- [ ] Chỉ cung cấp khóa cho Hermes trong môi trường an toàn.

## 7. Chẩn Đoán Lần 2 Với Dữ Liệu Sâu

- [ ] Hermes dùng thêm dữ liệu từ API/dữ liệu phân tích.
- [ ] Có thể xem xét lượt xem.
- [ ] Có thể xem xét lượt nhấp nếu dữ liệu có sẵn.
- [ ] Có thể xem xét khả năng giữ chân người xem nếu dữ liệu có sẵn.
- [ ] Hermes so sánh nhận định mới với chẩn đoán ban đầu.
- [ ] Cập nhật lại danh sách ưu tiên cải thiện.

## 8. Tạo Tài Sản Nội Dung Từ Dashboard

- [ ] Yêu cầu Hermes tạo dashboard hoặc hình ảnh có thể dùng trong video.
- [ ] Xuất màn hình/dashboard nếu cần.
- [ ] Tạo dàn ý video giải thích quá trình chẩn đoán.
- [ ] Tạo danh sách tiêu đề tiềm năng.
- [ ] Tạo ý tưởng ảnh đại diện video.
- [ ] Tạo danh sách hành động cho 30 ngày tới.

## 9. Ghi Nhớ Quy Trình Cho Lần Sau

- [ ] Lưu cách Hermes đã phân tích kênh.
- [ ] Lưu công cụ tạo video thường dùng.
- [ ] Lưu công cụ chuyển văn bản thành giọng nói nếu có.
- [ ] Lưu định dạng dashboard/hình ảnh ưa thích.
- [ ] Lưu cách người dùng muốn nhận báo cáo.
- [ ] Lưu các quyết định đã chọn để Hermes không hỏi lại ở lần sau.

## 10. Ghi Chú An Toàn

- [ ] Không ghi khóa API, mã truy cập OAuth, dữ liệu phân tích riêng hoặc dữ liệu kênh nhạy cảm vào kho dự án.
- [ ] Không chia sẻ dashboard nếu còn chứa dữ liệu riêng tư.
- [ ] Không bịa lệnh cài Hermes nếu chưa có nguồn chính xác.
- [ ] Không dùng dữ liệu công khai để kết luận thay cho dữ liệu phân tích sâu.
- [ ] Mỗi phiên chẩn đoán phải kết thúc bằng hành động cụ thể, không chỉ dừng ở nhận xét chung.
