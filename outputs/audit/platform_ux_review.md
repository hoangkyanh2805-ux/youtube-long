# Platform UX Review

Status: seed report.

## Surfaces Reviewed

| Surface | Current Role | Review Note |
|---|---|---|
| Daily report | Decision page | Good one-page structure; keep next actions above detail |
| Google Sheet | Control room | Preserve task IDs, status, owner, and review state |
| Telegram | Command channel | Use short messages and one primary action |
| Dashboard | Scan view | KPI, risk, and next action should be first screen |

## Required Before External Use

- Telegram message preview.
- Sheet range read-back.
- Human review for sales or offer copy.
