# XAUUSD Pre-Entry Checklist

#xauusd-checklist #risk-filter #live-setup-study

## Overview Table

| Item | Key Point |
| --- | --- |
| Bias | Session direction context |
| Liquidity | Area where price may sweep traders |
| Trigger | Confirmation condition |
| Invalidation | Price/context where the idea is wrong |
| Risk | Planned loss before entry |

## Core Concept

The checklist turns a live setup into an educational study plan. It forces the learner to define context, confirmation, failure point, and risk before thinking about an entry.

```text
Live setup
  -> Bias
  -> Liquidity
  -> Trigger
  -> Invalidation
  -> Risk
  -> Study-ready plan or skip
```

> [!important]
> If one box is missing, the setup is not ready.

> [!warning]
> This is not a trading signal. It is a risk filter for studying a setup.

## Exam/Test Patterns

| Scenario / Keyword | Answer |
| --- | --- |
| "Where is the setup wrong?" | Invalidation |
| "What confirms the setup?" | Trigger |
| "What should I do if one box is missing?" | Wait or skip |
| "Does this guarantee a winning trade?" | No |
